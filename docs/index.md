# POGF project documentation

This directory is the project's documentation. The documentation portal that
`deploy_docs.yml` was meant to publish has not been built: there is no
`mkdocs.yml`, and the workflow was disabled on 2026-09-24 after failing on all
of its runs (roadmap deliverable 3.1, pending).

Start here instead:

- [`../README.md`](../README.md): what the repository contains and how to run it.
- [`SETTLED.md`](SETTLED.md): what is already established, and what is still open.
- [`../CLAUDE.md`](../CLAUDE.md): architecture, what actually runs in production,
  measured component maturity, and the branching and merge rules.
- [`project_documentation/roadmap.md`](project_documentation/roadmap.md): deliverables and status.
- [`project_documentation/automation_stages.md`](project_documentation/automation_stages.md):
  the three processing stages and how far each is automated.
- [`bernese54_luzon_reprocessing_runbook.md`](bernese54_luzon_reprocessing_runbook.md):
  how production Bernese runs are done today.

Dated records (session logs, handovers, `CR-*` briefs, results notes) describe
what was true when they were written and are not updated afterwards.
