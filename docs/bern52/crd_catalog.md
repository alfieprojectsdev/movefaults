# CRD coordinate catalog

Generated by `scripts/build_crd_catalog.py` from **8,664 Bernese `.crd` files**
across `/srv/gnss-archive` and `$P`. Regenerate with the command in that
script's docstring; adding a root extends the catalog rather than replacing it.

**This is an identification index, not a coordinate product.** Its job is to
answer "which monument is this?" from an approximate position, to about 100 m —
the accuracy of a single-point position in a RINEX header. Frames and epochs
are deliberately not harmonised; see `SETTLED.md` for why.

## Accuracy check

Seven IGS stations whose true coordinates are independently known, against the
IGS20 reference file AIUB ships:

```
PIMO 0.15 m   ALIC 0.22 m   DAEJ 0.20 m   DARW 0.34 m
AIRA 0.36 m   GUAM 0.05 m   TSKB 0.50 m
```

Maximum deviation **0.50 m** — three orders of magnitude inside the ~100 m the
matching problem needs.

## Ambiguous codes — 118 sites

A 4-char code can name genuinely different monuments across eras. These are
**not averaged**: the published row is the largest position cluster, and
`n_clusters` / `cluster_extent_m` say how far the others sit.

The worst is instructive. **CATA** is three monuments: two Philippine sites
~220 km apart, plus an Argentine station that appears in a global ITRF
reference file. A naive median would place CATA in empty ocean between them.
