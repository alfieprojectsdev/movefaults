Dirnam32.dll version 4.10
	Append 'U' to Unicode library names to allow both Unicode and MBCS versions
        to coexist.  Unicode applications that link with the import library must relink
        with the new import library so that the proper DLL gets loaded at runtime.

Antenn32.dll version 4.30
	Append 'U' to Unicode library names to allow both Unicode and MBCS versions
        to coexist.  Unicode applications that link with the import library must relink
        with the new import library so that the proper DLL gets loaded at runtime.

	Added support for direct reading of ANTEX phase correction files.  Both
        single- and multiple-antenna files are support.  The name given for each
        antenna in the ANTEX file must match one of the RINEX aliases given for
        that antenna in the antenna.ini file.  IGS standardized names for known
        antennas are currently included in antenna.ini.

        Typically, customers will create a custom antenna.ini file with entries
        for each antenna for which they have an ANTEX file.  This will prevent
        their entries from being overwritten with Trimble config file updates.
        If the file contains a relative calibration model, the NGSCorrTable entry
        should reference the file.  If the file contains an absolute calibration
        model, the IFECorrTable entry should reference the file.  More than one
        antenna entry may reference the same file if the file contains multiple
        antenna phase models.  The library still supports reading Trimble PCT
        formatted files for NGS and IFE models and detects the proper format when
        reading the file.  Thus you can have a mix of PCT and ANTEX formatted files.

        While the library provides error codes when retrieving data from the
        phase table, these operations are usually done at a low level in processing
        where it would be difficult to alert a user to a possible decoding error.
        Thus users may not be aware that a phase table was not used in processing
        because of a decoding error. To help catch decoding errors early, three
        functions:
			ant_VerifyAntennaPhaseModelByName()
			ant_VerifyAntennaPhaseModelByType()
			ant_VerifyAntennaPhaseModelByCode()

        have been added to the library.  When called, these functions will read the
        phase table for the given antenna and selected model and verify proper decoding.
        Further, once the table is successfully read, it is cached in memory so that
        future references to the table will read from memory rather than disk.

        This DLL is backward compatible with previous versions so that existing
        applications can take advantage of the ANTEX capabilities without relinking.
        Applications that wish to use the new verify functions will need to relink
        with the new import library however.

Antenna.ini version 5.07
    Added entry for ADV Null Antenna.

    This entry is to identify RTK base stations that transmit observation data
    that has already been corrected for the base antenna model. Transmitting
    this model tells the rover RTK engine not to apply any model corrections
    to these observations when generating an RTK solution.

    Since this is a special case and does not represent a physical antenna,
    the special type id of 255 has been assigned for it.  Even though antenna
    type has been defined as a int16 some formats (CMR) only reserve an int8
    for this id. 255 was chosen to maintain compatibility with these formats.

    Note that while recent releases of office software should be able to
    handle the gap in sequence, older software may not. Testing is being done
    to check for possible compatibility issues. It is highly recommended that
    you save your previous ini file before installing this version. If your
    office software behaves erratically, restore to the previous version.
